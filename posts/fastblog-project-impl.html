背景

这个博客本身就是用 fastblog 生成的。fastblog 是个 Python 写的静态 博客生成器：在 content/ 写 Markdown，一条命令渲染成静态 HTML， 再推送到 GitHub 由 Actions 自动发布。这篇拆一下它的实现。

整体结构

核心代码在 staticgen/ 包里（模块名沿用了旧名字，品牌是 fastblog）， 按职责分了几个模块：

staticgen/
├── cli.py          # 命令行入口（build / serve / deploy）
├── config.py       # 配置加载，缺失字段回退默认值
├── engine.py       # 构建编排：插件→解析→渲染→拷贝静态资源
├── readers/        # Markdown 扫描、frontmatter 解析、正文渲染
├── renderers/      # Jinja2 渲染器与主题继承链
├── plugins/        # 插件基类与上下文
└── deploy/         # GitHub Pages 部署

构建的数据流：config → engine 加载插件 → readers 解析文章 → renderers 渲染模板 → 输出 output/。

配置加载：缺了也不崩

config.py 把所有配置聚合成几个 dataclass（SiteConfig、BuildConfig、 ServeConfig、DeployConfig），每个字段都有默认值。加载时逐个 site.get("title", DEFAULT_SITE_TITLE)，缺字段就回退，所以 config.yaml 写一半也能跑。布尔字段还做了字符串兼容 （"false" 不会被 bool() 误判成 True）。

文章解析：frontmatter + 渲染 + slug 冲突

readers/markdown_reader.py 用 python-frontmatter 解析 YAML/TOML 元数据，正文交给 python-markdown 的 extra / codehilite / toc 三个 扩展。有两个细节我挺喜欢：

  • slug 冲突自动处理：两篇文章 slug 撞了，后一篇自动加 -2 后缀， 不会互相覆盖输出文件
  • 单篇损坏不阻断：解析失败只打警告跳过，构建照常完成

文章按日期降序排列，无日期的排最后。

主题继承链：子主题覆盖父主题

renderers/jinja_renderer.py 会沿着 theme.yaml 的 parent 字段 向上找父主题，得到一个「子在前、父在后」的目录链。Jinja2 的 ChoiceLoader 按这个顺序加载模板，同名模板子主题优先——相当于 继承 + 覆盖。模板里还能用 url_for() 生成绝对路径，dateformat 过滤日期，now 取构建时刻。

构建编排与插件钩子

engine.py 的流程很直白：

  1. 加载 plugins/ 下所有继承 Plugin 的类并实例化
  2. 触发 on_init → 解析文章 → 解析主题链
  3. 清空输出目录（保留 .git，部署历史不丢）
  4. 触发 before_generate → 渲染首页和每篇文章 → 拷贝静态资源
  5. 触发 after_generate

插件三钩子各干各的：初始化、渲染前干预（可以改 ctx.posts）、 渲染后收尾。钩子抛异常只打警告不中断构建。

部署：产物仓库模式

deploy/github.py 走的是「产物仓库 + GitHub Actions」路线：输出 目录自己就是个 git 仓库，deploy 命令构建、提交、强制推送到 github-io/main，线上 pages.yml 工作流把仓库内容直接发布到 Pages。有个容易踩的坑：build 每次清空 output/ 会把 pages.yml 一并删掉，所以 deploy 前会自动按内置模板恢复它。

一些实现经验

  • 容错优先：全项目 IO 都包 try/except，单篇文章、单插件坏了 都不影响整体构建，这对「不知道哪天会写出什么 markdown」的博客 很关键
  • 幂等构建：每次清空重建，产物和源码一一对应，不会残留脏文件
  • 配置隔离：config.yaml 不进 git，config.example.yaml 才是 模板，密钥类信息天然不泄

结语

翻完整个项目你会发现没有一处复杂架构，就是十几个文件，每个边界 都在回答同一个问题：坏了怎么办。文章解析失败不阻断构建，插件 抛异常只打警告，配置缺字段自动回退，主题目录找不到就退回 default。 写的人只管写 markdown，剩下的它自己兜底。

背景

最近把 Logseq 里零散的 JVM 学习笔记整理到一起，顺便补全了当时没写 完整的部分。这篇就是整理结果，配图沿用原笔记的图。

JVM 基础大纲

Java 源代码先编译为二进制字节码 .class，再由 ClassLoader 加载进 JVM。之后的运行路径大致是：

  • 类 → 方法区
  • 实例对象 → 堆
  • 实例对象调用方法 → 虚拟机栈、程序计数器、本地方法栈
  • 方法执行时每行代码 → 执行引擎中的解释器
  • 被频繁调用的代码 → JIT 即时编译器
  • 不再被引用的对象 → GC 垃圾回收
  • 必须调用操作系统功能的方法 → 本地方法接口

程序计数器

程序计数器的作用是记住下一条 JVM 指令的执行地址，物理上通过 寄存器实现。指令链路是：JVM 指令 → 解释器 → 机器码 → CPU。

多线程运行时靠时间片切换，线程 1 时间片耗尽切到线程 2 时，程序 计数器保存线程 1 下一条指令的地址——这个计数器属于线程 1 自己， 每个线程都有各自的程序计数器。

两个特点值得记牢：

  • 线程私有
  • 不会内存溢出（整个 JVM 里唯一不会 OOM 的区域）

虚拟机栈

栈帧是每个方法运行时需要的内存：方法调用压栈，返回弹栈。 图中的栈帧结构是基础，后面学 GC 和 JIT 还会用到。

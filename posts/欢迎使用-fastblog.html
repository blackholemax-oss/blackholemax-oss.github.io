什么是 fastblog？

fastblog 是一个静态博客生成器：你在 content/ 目录下撰写 Markdown 文件，运行 python -m staticgen.cli build 即可生成 完整的静态 HTML 网站，并可通过 GitHub 一键部署。

特性一览

功能 状态 说明
Markdown 渲染 已启用 基于 python-markdown，含 Tables 扩展
代码高亮 已启用 基于 Pygments 的 CodeHilite 扩展
目录生成 已启用 TOC 扩展，插入 [TOC] 占位符
元数据解析 已启用 YAML / TOML Frontmatter
